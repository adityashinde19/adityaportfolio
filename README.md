# Aditya Shinde — Portfolio

Futuristic portfolio built with React 19, TypeScript, Vite, Tailwind CSS v4, Motion, Three.js (React Three Fiber) and Lenis smooth scrolling.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

Edit all content (projects, skills, links) in `src/data.ts`.
The resume download is served from `public/Aditya_Shinde_Resume.pdf`.
